Reading a shared chart

Someone sent you a floss list or a printed chart made with Sampler. This page says what each part means.

The floss list

The first lines name the project and give its size in stitches, the fabric count and cloth, and the finished size in centimetres and inches.

Then each thread has a line of its own: a DMC number, the colour's name and how many skeins it needs. The DMC numbers are a colour reference, so you can match each thread wherever stranded cotton is sold.

When the stitcher has marked the threads they own, the list splits in two. The first group holds the threads still needed, each with its skeins. The second group, Already have, holds the threads the stitcher owns.

The printed chart

Start at A1. The page map on page 2 shows how the chart pages fit together: letters run across, numbers run down, and A1 is the top-left page.

Where two pages meet, expect 2 repeated stitches: each page repeats 2 stitches from the page before it, shaded, so the pages line up. Stitch them once.

The legend gives every thread its symbol, DMC number, name, stitch count and skeins. Its PAGES column names the chart pages that use the thread, so you can lay out the colours for a page before you start it.

The last pages repeat the floss list with a box beside each thread to tick off.

Colour numbers refer to DMC® stranded cotton for reference; Sampler is not affiliated with DMC.
